# 📅 WA Scheduler — جدولة رسائل واتساب بيزنس من الهاتف

سيرفر صغير يعمل **داخل Termux على هاتف أندرويد** ويرسل رسائل واتساب مجدولة في الخلفية، 24 ساعة في اليوم، بدون أن تفتح أي تطبيق أو تضغط أي زر.

> ⚠️ **تنبيه:** هذا المشروع يستخدم مكتبة [Baileys](https://github.com/WhiskeySockets/Baileys) غير الرسمية، أي أنه يخالف شروط استخدام واتساب. استخدمه بحذر: لا ترسل لأرقام لم تتواصل معها، ولا ترسل كميات كبيرة، وتجنّب الرسائل الدعائية. الحساب قد يُحظر في أي وقت، والمشروع لا يتحمّل أي مسؤولية عن ذلك.

---

## ✨ المميزات

- **جدولة الرسائل** لأي وقت في المستقبل، بحسب توقيت منطقتك.
- **أنواع المحتوى:** نص، صورة، فيديو، صوت، أو أي ملف (PDF، Word، …).
- **عدة مستلمين:** أرقام متعددة، أو مجموعات واتساب، أو جهات اتصالك المحفوظة.
- **التكرار:** مرة واحدة، أو كل يوم، أو كل أسبوع، أو كل شهر.
- **تعديل وحذف** أي رسالة مجدولة، و**إرسال فوري** عند الحاجة.
- **فاصل عشوائي** (3 إلى 8 ثوانٍ) بين المستلمين لتقليل خطر الحظر.
- **يعيد الاتصال وحده** إذا انقطع الإنترنت، ويكمل الإرسال من حيث توقف.
- **يعيد تشغيل نفسه** إذا توقف، ويعمل بعد إعادة تشغيل الهاتف.
- **واجهة ويب بالعربية** (RTL) مصممة للجوال، ومحمية بكلمة سر، وتعمل من أي جهاز على نفس شبكة الواي فاي.
- **لا يرسل رسائل فاتها موعدها** بأكثر من 3 ساعات تلقائياً، بل يعرضها لك لتقرر.

## 📋 المتطلبات

- هاتف أندرويد (يُفضّل 8 أو أحدث) مع **حوالي 300 ميغا** فارغة على الأقل.
- حساب **واتساب بيزنس** على رقم هاتف.
- تطبيقات من **F-Droid** (وليس Play Store، لأن نسخة Play قديمة ومعطّلة):
  - [Termux](https://f-droid.org/packages/com.termux/)
  - [Termux:Boot](https://f-droid.org/packages/com.termux.boot/) — للتشغيل التلقائي بعد إعادة تشغيل الهاتف
  - [Termux:API](https://f-droid.org/packages/com.termux.api/) — لمراقبة السيرفر وإعادة تشغيله

## 🚀 التثبيت (مرة واحدة)

1. ثبّت التطبيقات الثلاثة السابقة من F-Droid.
2. افتح **Termux:Boot** مرة واحدة ثم أغلقه.
3. نزّل ملف `wa-scheduler-setup.sh` ([من صفحة Releases](../../releases)) وانقله إلى مجلد **Download** في الهاتف.
4. افتح Termux واكتب:

```bash
termux-setup-storage
```

```bash
bash ~/storage/downloads/wa-scheduler-setup.sh
```

5. انتظر من 5 إلى 10 دقائق حتى يكتمل التثبيت.
6. افتح Chrome على العنوان: **http://localhost:8080**
7. أنشئ كلمة سر للصفحة.
8. من **الإعدادات** في الصفحة، أدخل رقم واتساب بيزنس واطلب الرمز.
9. في واتساب بيزنس: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف بدلاً من ذلك**، ثم أدخل الرمز.

> بعد الربط مرة واحدة لا تحتاج إلى الرمز مجدداً، حتى بعد إعادة تشغيل الهاتف.

## ⚙️ إعداد الهاتف حتى لا يتوقف (مهم جداً)

أندرويد يقتل التطبيقات في الخلفية افتراضياً. اضبط التالي:

- **الإعدادات ← التطبيقات ← Termux ← البطارية ← غير مقيّد** (وكرّر ذلك لـ Termux:Boot و Termux:API).
- **سامسونج:** الإعدادات ← البطارية ← حدود الاستخدام في الخلفية ← أضف Termux إلى **"التطبيقات التي لا تُنام أبداً"**، وأوقف "وضع النوم للتطبيقات غير المستخدمة".
- **شاومي / أوبو / فيفو / هواوي:** فعّل **التشغيل التلقائي** لـ Termux، وأضفه إلى قائمة **"عدم القتل"** أو **"Lock in recent"** في الأحداث الأخيرة.
- اترك الهاتف **على الشاحن** مع **واي فاي** متصل.
- اضغط على إشعار Termux واختر **ACQUIRE WAKELOCK** (إذا ظهر الخيار).

## 🧭 أوامر التحكم داخل Termux

| الأمر | الوظيفة |
|---|---|
| `wa status` | هل السيرفر يعمل؟ |
| `wa start` | تشغيل السيرفر |
| `wa stop` | إيقاف السيرفر |
| `wa restart` | إعادة التشغيل |
| `wa log` | آخر سطور السجل |
| `wa open` | فتح الصفحة في المتصفح |

## 🔄 التحديث

انزّل ملف setup الجديد وشغّله بنفس أمر التثبيت. بياناتك (الربط، الرسائل المجدولة، جهات الاتصال) محفوظة في `~/wa-scheduler/data` ولن تُحذف.

## 🛠️ حل المشاكل

| المشكلة | الحل |
|---|---|
| السيرفر يتوقف بعد ساعة أو ساعتين | أندرويد يقتله. راجع قسم **إعداد الهاتف** أعلاه، وتأكد أن إشعار Termux ظاهر. |
| الصفحة لا تفتح على `localhost:8080` | اكتب `wa status`. إذا كان متوقفاً اكتب `wa start`. |
| "ثبّت Termux:API" في التثبيت | ثبّت Termux:API من F-Droid وأعد تشغيل التثبيت. |
| الرمز لا يُقبل في واتساب | اطلب رمزاً جديداً من الصفحة، واستعمله خلال دقيقتين. |
| "هذا الرقم غير موجود على واتساب" | تأكد من الرقم ورمز الدولة. الإعداد الافتراضي للدولة في الإعدادات. |
| الرسالة فاتت موعدها | ستظهر بحالة "فات موعدها". اضغط **أرسل الآن** إذا أردت إرسالها. |
| فصل الجهاز من واتساب | يجب الربط من جديد من الإعدادات. |
| نفاد المساحة | احذف الملفات الكبيرة من الهاتف. الملفات المرسلة تُحذف تلقائياً. |

لعرض السجل التفصيلي: `wa log`، أو من الصفحة: **الإعدادات ← سجل التشغيل**.

## 🔒 الأمان والخصوصية

- كل البيانات على **هاتفك فقط**، ولا يوجد أي سيرفر خارجي.
- الصفحة محمية بكلمة سر، ولا تُفتح إلا من شبكتك المحلية.
- **لا تفتح المنفذ 8080 على الإنترنت** (لا تفعل port forwarding على الراوتر).
- ملف الربط في `~/wa-scheduler/data/auth` يعطي وصولاً كاملاً لحسابك، لا تشاركه أبداً.

## 🧩 هيكل المشروع

```
wa-scheduler/
├── server.js          # السيرفر: الاتصال بواتساب، الجدولة، واجهة API
├── public/index.html  # الواجهة العربية
├── run.sh             # حلقة تبقي السيرفر يعمل وتعيد تشغيله
├── install.sh         # تثبيت Node والمكتبات والتشغيل التلقائي
├── bin/wa             # أوامر التحكم
├── bin/watchdog       # مراقب يعمل كل 15 دقيقة من نظام أندرويد
├── build-setup.sh     # يبني ملف التثبيت الواحد
└── dist/wa-scheduler-setup.sh   # ملف التثبيت النهائي
```

## 👩‍💻 للمطورين

```bash
# تجربة على الحاسوب
npm install --legacy-peer-deps
PORT=8090 node server.js
# ثم افتح http://localhost:8090

# بناء ملف التثبيت للهاتف
bash build-setup.sh
```

ملاحظة: `--legacy-peer-deps` ضرورية لأن مكتبة `sharp` اختيارية وتثقل التثبيت على الهاتف.
